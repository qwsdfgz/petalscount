CSRNet-petalscount
This repository is for petalscount project. The model weight and test images are provided.

Environment & Folders
python 3.10.14
pytorch 2.4.0
torchvision 0.19.0
numpy 1.23.5
tensorboard 2.17.0


images: Image information used for testing tasks.
gt: Density map in .h5 format.
0model_best.pth.tar：Model weights used for testing.
model.py: Model file.
test.py: test file.

Testing Process
